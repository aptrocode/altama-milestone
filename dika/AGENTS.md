# Agent Guide for `dika/` Workspace

> ⚠️ **CRITICAL DIRECTIVE FOR ALL AI AGENTS & CONTRIBUTORS WORKING HERE**
>
> 1. **DILARANG KERAS MENGUBAH FILE DI LUAR FOLDER `dika/`**
>    - **DO NOT TOUCH, EDIT, OR DELETE ANY FILES OUTSIDE THIS DIRECTORY (`dika/`).**
>    - Seluruh kode di root dan subfolder lainnya (`app/`, `docs/`, `public/`, `shared/`, `test/`, `package.json`, dll.) adalah sistem pameran LED resmi Nuxt 4 yang dikelola langsung oleh **Adityawarman Dewa Putra (@adydetra / Dewa)**.
> 2. **BATASAN KERJA (SCOPE)**
>    - Ruang lingkup kerja Dika dan AI Agent-nya adalah **100% di dalam folder `dika/`**.
>    - Silakan buat file HTML, CSS, JS, aset, mockup, atau prototipe tampilan secara bebas **hanya di dalam folder `dika/`** (contoh: `dika/index.html`, `dika/style.css`, dll.).
> 3. **PROSES INTEGRASI KE APLIKASI UTAMA (HANDOFF)**
>    - Jangan mencoba mengintegrasikan sendiri kode prototipe ke dalam folder `app/` atau membuat folder baru di root (seperti `mainProject`).
>    - Jika desain atau prototipe di dalam `dika/` sudah selesai dan ingin diintegrasikan ke aplikasi pameran utama, **laporkan/serahkan ke Dewa (@adydetra)**.
>    - Dewa yang akan mengonversi (*porting*) logika dan styling ke komponen Vue 3, Tailwind CSS v4, dan Pinia store resmi.
